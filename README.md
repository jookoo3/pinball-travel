# Pinball Travel

한반도 지도를 무대로 하는 웹 핀볼 여행지 추천 게임입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## GitHub Pages 배포

- 저장소 이름: `pinball-travel`
- 기본 브랜치: `main`
- `.github/workflows/deploy.yml` 이 자동 배포합니다.
- GitHub 저장소 설정에서 **Pages > Build and deployment > Source** 를 **GitHub Actions** 로 설정하세요.
